  [BUG NYATA dikonfirmasi live, TC-ADMIN-STRUCTURE-07 SENGAJA DIBIARKAN
  FAILED] Menambah unit baru mengirim unitId="" dan description=""
  (string kosong, field OPSIONAL) ke POST /api/v2/admin/subunits, tapi
  server menyimpan dan mengembalikannya sebagai `null`. Saat unit itu

  ["unitId","description"]), padahal KEDUA field itu opsional (bukan di
  daftar "* Required"). Akibatnya: SETIAP unit yang baru ditambah TIDAK
  BISA di-rename lagi tanpa dulu mengisi Unit Id dan Description secara
  manual -- regresi nyata antara flow Add (longgar menerima "") dan flow
  Edit (strict menolak null) untuk field opsional yang sama. Temuan ke-2
  di suite Admin ini (setelah TC-ADMIN-JOBTITLE-07), bug pattern BEDA
  (bukan upload-security, tapi null-vs-empty-string pada field opsional
  antara create dan update).
