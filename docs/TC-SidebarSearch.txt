  FUNGSI & PERILAKU YANG DIBUKTIKAN LIVE (16 Nov 2026)
================================================================================

  Kotak Search menyaring daftar modul sidebar langsung di browser:
  -> pencocokan potongan teks, tidak peka huruf besar/kecil, HANYA atas nama
     modul (Admin, PIM, Leave, ...); nama sub-menu seperti "Leave List" tidak
     ditemukan.
  -> mengetik TIDAK mengirim request apa pun ke server. Karena itu item taksonomi
     yg menilai respons server (5.6 header per dokumen, 5.8, 6.1-6.5) ditandai
     N/A di matrix dgn flag NOAPI, berdasarkan bukti di TC-SIDEBAR-SEARCH-02.
  -> query tanpa hasil mengosongkan menu tanpa teks "No results"; query spasi
     saja tidak di-trim (semua modul tersembunyi). Keduanya dicatat sbg finding.
