  API ENDPOINT ADD EMPLOYEE (CONFIRMED):
    POST /web/index.php/api/v2/pim/employees
    - Sukses -> status 200, body:
        {"data":{"empNumber":N,"lastName":"...","firstName":"...",
                  "middleName":"...","employeeId":"NNNN","terminationId":null},
         "meta":[],"rels":[]}
    - Employee Id duplikat -> request TIDAK PERNAH TERKIRIM. Validasi client-
      side memblokir submit dengan pesan "Employee Id already exists" sebelum
      POST dipanggil.
    - Employee Id field: ada BATAS PANJANG 10 KARAKTER client-side, payload
      apa pun di atas 10 karakter (termasuk payload mirip XSS seperti
      "<script>x</script>", 21 char) diblokir oleh validasi panjang dengan
      pesan "Should not exceed 10 characters", BUKAN oleh filter XSS khusus.
      Ini dicatat sebagai temuan di TC-PIM-ADD-20, bukan bukti proteksi XSS
      yang sesungguhnya, payload XSS yang MUAT di bawah 10 karakter belum
      tentu tertangkap.
    - Whitespace-only First/Last Name -> di-trim client-side jadi kosong,
      memicu validasi "Required" sama seperti pola di Login (TC-LOGIN-15/16).

  API ENDPOINT EMPLOYEE LIST (CONFIRMED):
    GET /web/index.php/api/v2/pim/employees?limit=50&offset=0&model=detailed
        &includeEmployees=onlyCurrent&sortField=employee.firstName&sortOrder=ASC
    - Filter Employment Status -> query param sebenarnya adalah `empStatusId`,
      BUKAN `employmentStatus` (ditemukan salah asumsi awal, dikoreksi di
      TC-PIM-LIST-03, pelajaran yang sama seperti kasus username
      case-insensitive di Login: verifikasi langsung, jangan asumsi nama
      param dari UI label).
    - Search Employee Id TIDAK PUNYA batas panjang client-side (beda dari
      Employee Id di form Add Employee yang dibatasi 10 karakter), ID
      pencarian >10 karakter mengembalikan HTTP 422 dari server, dan UI
      diam-diam fallback menampilkan SEMUA record alih-alih "No Records
      Found". TC-PIM-LIST-09 disesuaikan memakai ID valid (bukan >10 char)
      dan mendokumentasikan perilaku 422-silent-fallback sebagai temuan
      terpisah.

    4 dropdown filter (Employment Status, Include, Job Title, Sub Unit) di-

  LOCATORS & PERILAKU KONFIRMASI (PersonalDetailsPage.ts):
