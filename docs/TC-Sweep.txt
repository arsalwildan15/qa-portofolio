================================================================================
  FUNGSI & ALASAN PENDEKATAN
================================================================================

  Sebagian item docs/Test-Case-Taxonomy.txt berlaku untuk SETIAP menu dengan cara
  pemeriksaan yang identik (contoh: header keamanan 5.6, console error 7.1, request
  gagal 7.2, aset 404 7.3, waktu muat 7.5). Menulis satu file per menu untuk hal yang
  sama akan menghasilkan ratusan file kembar. TC sweep membaca daftar unit menu dari
  src/data/unitRegistry.ts (dibangun dari inventaris LIVE: setiap item sidebar & top-nav
  diklik satu per satu, 15 Nov 2026) dan memeriksa setiap unit dalam satu run. Setiap
  check diberi label [U### Path Menu], sehingga hasilnya tetap bukti PER MENU dan bisa
  ditelusuri ke sel docs/Taxonomy-Coverage-Matrix.xlsx.

  Unit yang URL-nya butuh ID record (halaman detail) me-resolve ID dari API secara
  read-only saat run. Bila data demo sedang kosong, unit itu dicatat sbg finding
  "dilewati" -- tidak dianggap lolos.
